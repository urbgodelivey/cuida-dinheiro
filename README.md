# Cuida Dinheiro

MVP PWA de gestão financeira pessoal.

## Funções
- Entradas e saídas
- Contas a pagar
- Dinheiro livre (saldo - contas pendentes)
- "Posso gastar?"
- Resumo financeiro
- Cor principal configurável
- Tema claro/escuro
- Dados locais no aparelho via localStorage
- Instalável como PWA
